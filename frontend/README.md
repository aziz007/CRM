# CRM frontend

Angular 22 with Angular Material. Standalone components, reactive forms, route guards and an HTTP interceptor for the JWT.

## Development

```bash
npm install
npm start          # http://localhost:4200
```

The API base URL defaults to `http://localhost:4000/api/v1` and is set in `src/app/core/api.config.ts`. Change it there for other environments.

## Build

```bash
npm run build
```
